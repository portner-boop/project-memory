# 10 — Roadmap

## Версия 1 — локальный CLI

Без backend, PostgreSQL и MCP.

**Стек**

```text
Python
Typer
Pydantic
PyYAML
markdown-it-py
Git через subprocess
Jinja2
JSON Schema
```

**Команды**

```text
repomind init
repomind task
repomind plan
repomind sync
repomind check
repomind index
```

**Распространение**

```bash
uvx repomind init
```

**Критерий готовности v1:** на реальном проекте можно провести задачу от
`repomind task` до зелёного `repomind check`, и постоянная документация
меняется только там, где реально изменилось поведение.

---

## Версия 2 — skills и hooks

Добавить:

- Claude Code skill;
- Codex skill;
- Claude hook;
- pre-commit hook;
- GitHub Action.

**Критерий готовности v2:** разработчик не вызывает CLI руками — sync
запускается сам в нужный момент, а CI ловит забытое.

---

## Версия 3 — Jira и GitHub

Только здесь нужен MCP или API-интеграция.

```text
Jira task
   ↓
repomind task
   ↓
implementation
   ↓
PR
   ↓
PM summary и result обратно в Jira
```

**Критерий готовности v3:** ТЗ не копируется руками, а PM видит summary
в Jira без участия разработчика.

---

## Версия 4 — командный сервис

Backend нужен **только** для:

- общей панели проектов;
- статистики покрытия документацией;
- централизованных правил;
- согласования ADR;
- работы между несколькими репозиториями;
- корпоративных политик;
- истории расходов моделей.

Всё, что можно оставить в Git, остаётся в Git. Backend не становится источником
правды по документации — источник правды всегда репозиторий.
