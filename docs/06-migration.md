# 06 — Переезд с текущего flow

Если у тебя уже есть папка на Jira-задачу, deep-dive, оценка и описание для
менеджера — ты в одном шаге от системы. Текущий процесс **не заменяется,
а обрастает структурой**.

## Оставить как есть

- Jira ID как имя директории;
- исходное ТЗ;
- технический deep dive;
- оценку в часах;
- summary;
- отдельные frontend/backend инструкции;
- документацию в markdown;
- хранение всего в Git.

## Добавить

| Что | Зачем |
|---|---|
| стабильные ID документов и блоков | адресное обновление вместо переписывания файла |
| `docs/_index.json` | агент находит нужные документы за один шаг |
| ADR | фиксируется *почему*, а не только *как* |
| `last_verified_commit` | видно, что давно не подтверждали |
| автоматический `git diff` | определение влияния без участия человека |
| structured output от модели | модель не пишет в файлы напрямую |
| `/docs-check` | дисциплина обеспечивается скриптом, а не памятью |
| единый скилл на Claude Code и Codex | один процесс на двух агентов |

## Убрать

- ручное обновление каталогов;
- полный анализ всей документации после каждой задачи;
- постоянное переключение больших инструкций;
- метки по номерам строк в постоянной документации;
- отдельного субагента на каждую мелкую операцию;
- обязательный глоссарий для каждого проекта.

## Порядок

1. **`/docs-init`** — каркас, `AGENTS.md`, `CLAUDE.md`, скиллы. Заодно, если
   установлен [CodeGraph](07-codegraph.md), построит первичный индекс кода —
   фоном, пока разворачивается структура.
2. **Перенести существующую документацию** в `product/`, `architecture/`,
   `contracts/` — **без переписывания текста**.
3. **Проставить frontmatter** — `id`, `type`, `code_paths`.
4. **Разметить блоки** там, где документ длиннее экрана.
5. **`/docs-check`** — собрать каталог и увидеть список битых ссылок
   и недостающих полей. При доступном CodeGraph он же заполнит `symbols`.
6. **Завести ADR задним числом только для решений, которые до сих пор спорны.**
7. Позже — хуки и CI.

Шаг 6 — самый частый способ потерять неделю. **ADR пишутся вперёд, а не назад.**
Ретроспективно фиксируем только то, что реально переспрашивают.

## Что менять в существующих документах

Единственная обязательная правка в тексте — ссылки на код:

```text
❌ backend/app/auth/service.py:142
✅ backend/app/auth/service.py#AuthService.refresh
```

Номера строк устаревают на первом же рефакторинге и не проверяются скриптом.
Всё остальное содержимое переносится как есть.
