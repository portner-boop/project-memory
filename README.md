# RepoMind

> **Инкрементальная память проекта для разработчиков и coding agents.**
> Документация, которая развивается вместе с кодом.

Этот репозиторий — **спецификация продукта**: концепция, модель документации,
рабочий пример и шпаргалка. Кода CLI здесь пока нет.

---

## Проблема

Типичный рабочий flow вокруг Jira-задачи уже содержит всё нужное — ТЗ,
технический разбор, план, описание для PM, папку на задачу. Но держится он
целиком **на ручной дисциплине**. Никто не гарантирует, что после мержа
документация обновлена, а агент не знает, какие именно файлы ему читать.

## Решение

Превратить документацию из набора файлов в машиночитаемую память проекта:

```text
Git и скрипты
    ↓
находят изменения и нужные документы
    ↓
один короткий вызов LLM
    ↓
возвращает структурированные операции
    ↓
скрипты применяют и проверяют изменения
    ↓
человек видит обычный Git diff
```

Не «главный умный агент с четырьмя субагентами», а гибрид: дорогое отдаётся
модели, дешёвое — скриптам.

## Пять принципов

1. **Атомарные блоки.** Агент обновляет блок `AUTH.REFRESH_TOKEN`, а не весь
   `architecture.md`.
2. **Решения фиксируются отдельно.** Код показывает *как*; ADR отвечает
   *почему*.
3. **Каталог генерируется скриптом.** `_index.json` строится из frontmatter —
   LLM здесь не нужна.
4. **Модель не пишет в файлы.** Она возвращает валидируемые операции с
   обязательным `evidence`.
5. **Токены зависят от размера изменения, а не проекта.** В модель уходит
   только diff и связанные блоки.

## Пример за 30 секунд

Документ разбит на адресуемые блоки:

```md
---
id: ARCH-AUTH
type: architecture
code_paths:
  - backend/app/auth/**
last_verified_commit: a91d2f4
---

## Обновление токена
<!-- block: AUTH.REFRESH_TOKEN -->

Refresh token хранится в HTTP-only cookie.
Основная реализация: `backend/app/auth/service.py#AuthService.refresh`.
```

Модель возвращает операцию, а не текст файла:

```json
{
  "action": "replace_block",
  "document_id": "PRODUCT-CONTESTS",
  "block_id": "CONTEST.DEFAULT_SORTING",
  "content": "По умолчанию конкурсы сортируются...",
  "evidence": ["backend/app/contest/service.py#ContestService.get_all"],
  "confidence": 0.94
}
```

Скрипт применяет — человек ревьюит в обычном Git diff.

Полный сквозной сценарий: [examples/demo-project/](examples/demo-project/).
