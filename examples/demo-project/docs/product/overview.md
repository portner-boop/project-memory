# Обзор продукта

## Что это за система
<!-- block: OVERVIEW.WHAT -->

Платформа приёма и сопровождения заявок на гранты. Две роли:

- **грантополучатель** — подаёт заявку, ведёт проект по этапам, сдаёт отчёты;
- **куратор** — проверяет отчёты, принимает или возвращает на доработку.

## Основной сценарий
<!-- block: OVERVIEW.FLOW -->

```text
заявка → одобрение → проект разбит на этапы
                          │
                          ├─ по каждому этапу: финансовый отчёт с расходами
                          ├─ куратор проверяет и принимает
                          └─ принятый этап неизменен, значения зафиксированы
```

Модель заявки: `backend/app/application/models.py#Application`.

## Ключевые понятия
<!-- block: OVERVIEW.GLOSSARY -->

| Термин | Что значит |
|---|---|
| **Заявка** | обращение за грантом; после одобрения становится проектом |
| **Этап** | период проекта с датами начала и окончания |
| **Отчёт** | финансовый отчёт за период, привязан к этапу |
| **Расход** | строка в отчёте: категория и сумма |
| **Принятие** | подтверждение куратором; после него данные замораживаются |
| **Legacy** | заявки до 2024 года, работают по отдельной ветке кода |
