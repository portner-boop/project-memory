# docs/

Память проекта. Читается людьми и coding agents.

## Точка входа для агента

[`_index.json`](_index.json) — каталог документов, блоков и `code_paths`.
Генерируется командой `repomind index`, **руками не редактируется**.

## Разделы

| Каталог         | Содержимое                              | Постоянство |
| --------------- | --------------------------------------- | ----------- |
| `product/`      | обзор продукта, бизнес-правила          | постоянное  |
| `architecture/` | как устроена система                    | постоянное  |
| `contracts/`    | API, события                            | постоянное  |
| `decisions/`    | ADR — почему приняты решения            | append-only |
| `requirements/` | исходные ТЗ «как пришли»                | неизменяемое|
| `tasks/<ID>/`   | всё по конкретной Jira-задаче           | временное   |
| `now/`          | указатель на активную задачу            | перезаписывается |

## Правила

1. Каждый постоянный документ имеет `id`, `type` и `code_paths` во frontmatter.
2. Длинные документы разбиты на блоки `<!-- block: SCOPE.NAME -->`.
3. Ссылки на код — `path/to/file.py#Class.method`, **никогда не по номеру строки**.
4. `requirements/original/` не редактируется никогда.
5. Постоянная документация обновляется только при изменении поведения,
   контрактов, данных или архитектурных решений.

Полные правила — в `AGENTS.md` в корне проекта.
