# docs/

Память проекта. Читается людьми и coding agents.

## Точка входа для агента

[`_index.json`](_index.json) — каталог документов, блоков и `code_paths`.
Пересобирается скиллом `/docs-check`, **руками не редактируется**.

## Разделы

| Каталог | Содержимое | Время жизни |
|---|---|---|
| `product/` | что система делает | годы |
| `architecture/` | как она устроена | годы |
| `contracts/` | API и события | годы |
| `decisions/` | ADR — почему так решили | только дописывается |
| `runbook/` | как запустить, чем тестировать, что делать когда сломалось | меняется с процессом |
| `requirements/inbox/` | **сюда кидать `.docx` с ТЗ** | до `/docs-task` |
| `requirements/original/` | обработанные ТЗ | не редактируются никогда |
| `tasks/<ID>/` | всё по конкретной задаче | недели |
| `now/` | указатель на активную задачу | часы |

## Правила

1. Каждый постоянный документ имеет `id`, `type` и `code_paths` во frontmatter.
2. Длинные документы разбиты на блоки `<!-- block: SCOPE.NAME -->`.
3. Ссылки на код в постоянной документации — `path/to/file.py#Symbol`,
   **никогда не по номеру строки**.
4. `requirements/original/` не редактируется.
5. Постоянная документация обновляется только при изменении поведения,
   контрактов, данных или архитектурных решений.

Полные правила — в [`AGENTS.md`](../AGENTS.md) в корне проекта.
