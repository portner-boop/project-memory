## 2.1 Общее описание

В отчёте по этапу проекта в таблицах «Прямые расходы» и «Косвенные расходы»
добавить колонку «Расход за этап».

## 2.2 Требования

**2.2.1.** Колонка доступна только для чтения, грантополучатель значение не
вводит.

**2.2.2.** Значение колонки — сумма расходов по принятым отчётам, период
которых пересекается с периодом текущего этапа. Принятыми считаются отчёты
в статусах «Принят» и «Принят с замечаниями».

**2.2.3.** Значение отражает только период текущего этапа и не является
нарастающим итогом. На следующем этапе отображается сумма за период
следующего этапа.

**2.2.4.** Если пересекающихся принятых отчётов нет, отображается 0.

**2.2.5.** Существующая колонка «Расход всего» не изменяется.

**2.2.6.** Пока этап не принят, значение пересчитывается при принятии отчётов.
На принятом этапе значение фиксируется на момент принятия.

**2.2.7.** Расчёт и сохранение выполняются для всех заявок, включая заявки
старого образца. В интерфейсе и печатной форме заявок старого образца колонка
не отображается.

**2.2.8.** Для этапов, принятых до внедрения доработки, выполняется
единоразовое заполнение значений по тем же правилам на основании текущих
данных. Отдельные правила для таких этапов не вводятся.

**2.2.9.** Печатная форма отчёта дополняется новой колонкой. Колонка
располагается перед блоком «Итого по этапу».

## 2.3 Ограничения

**2.3.1.** Открытие этапа не должно замедлиться.

**2.3.2.** Корректность настройки периодов этапов и отчётов не проверяется,
расчёт выполняется строго по пересечению.

**2.3.3.** Выгрузка в разделе «Статистика» в рамках настоящего задания не
дорабатывается (связанное задание 2.23).
