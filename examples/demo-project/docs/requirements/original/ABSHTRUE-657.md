# ABSHTRUE-657 — Порядок конкурсов в списке

Исходное ТЗ, как пришло из Jira. Не редактируется.

---

Пользователи жалуются, что на странице конкурсов сверху оказываются старые
и уже закрытые конкурсы, а актуальные приходится искать.

Нужно, чтобы по умолчанию сверху были самые свежие конкурсы.

Сортировку пользователь по-прежнему может менять руками.
