# inbox — сюда кидать ТЗ

Перетащи сюда файл с техническим заданием и запусти:

Скажи агенту `/docs-task`.

Что понимает:

| Формат | Комментарий |
|---|---|
| `.docx` | основной сценарий, таблицы и картинки сохраняются |
| `.pdf` | текст и таблицы |
| `.xlsx` | таблицы требований |
| `.md` `.txt` | как есть |

Номер задачи берётся из имени файла (`ABSHTRUE-657.docx`,
`ТЗ ABSHTRUE-657 v2.docx`), из первых строк текста, а если не нашёлся —
спросят в терминале.

После обработки:

- оригинал переезжает в `../original/` и остаётся там навсегда;
- рядом ложится сконвертированный `.md`;
- создаётся `docs/tasks/<ID>/request.md`;
- эта папка очищается.

Можно кидать несколько файлов сразу — обработаются все.

> Оригинал сохраняется специально: конвертация может потерять схему или сложную
> объединённую ячейку. Если ТЗ важное — пробеги `request.md` глазами перед
> `/docs-plan`.
