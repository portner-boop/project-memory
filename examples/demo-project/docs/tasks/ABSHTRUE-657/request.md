# ABSHTRUE-657 — Порядок конкурсов в списке

## Постановка

Сверху списка конкурсов должны быть самые свежие конкурсы. Сейчас порядок
фактически произвольный — определяется порядком выборки из БД.

## Ссылка на исходник

[`docs/requirements/original/ABSHTRUE-657.md`](../../requirements/original/ABSHTRUE-657.md)

## Ограничения из ТЗ

- ручная сортировка пользователем должна сохраниться;
- изменение касается только порядка по умолчанию.
