# DEMO-657 — коротко

В таблицах расходов отчёта появится новая колонка «Расход за этап».

Сейчас видно только общую сумму, накопленную с начала проекта. Понять, сколько
потратили именно за текущий этап, можно только вычитанием в уме. Новая колонка
показывает это сразу. Заполняется автоматически, руками ничего вводить не надо.

После принятия этапа значение фиксируется и больше не меняется — как и
существующая колонка с общей суммой. Для этапов, принятых раньше, значение
досчитается один раз при выкатке. Колонка появится и в печатной форме.
У заявок старого образца всё останется как было.

**Оценка: 16 часов** — [estimate.md](estimate.md).
