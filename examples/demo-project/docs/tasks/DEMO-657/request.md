# DEMO-657 — Колонка «Расход за этап»

> Сконвертировано из `DEMO-657.docx`.
> Оригинал: [`docs/requirements/original/DEMO-657.docx`](../../requirements/original/DEMO-657.md)

## Что нужно сделать

В таблицах расходов отчёта добавить колонку **«Расход за этап»**:

1. Колонка read-only, грантополучатель значение не вводит.
2. Значение = сумма расходов по принятым отчётам (`accepted` /
   `accepted_with_notes`), период которых **пересекается** с периодом текущего
   этапа.
3. Это значение **только за период этапа**, НЕ нарастающий итог. На следующем
   этапе — значение за период того этапа.
4. Если пересекающихся принятых отчётов нет — отображается `0`.
5. Существующая колонка «Расход всего» (нарастающий итог) не меняется ни по
   смыслу, ни по правилам расчёта.
6. Пока этап не принят — значение пересчитывается при принятии отчётов;
   на принятом этапе — фиксируется на момент принятия, по аналогии с
   «Расход всего».
7. Расчёт и сохранение выполняются для **всех** заявок, включая legacy,
   но в UI и PDF legacy-отчётов колонка НЕ отображается.
8. Для этапов, принятых до внедрения, — единоразовая доливка по тем же правилам
   на основании текущих данных.
9. PDF-форма отчёта (кроме legacy) дополняется новой колонкой.
10. Колонка располагается **перед** блоком «Итого по этапу».
11. Открытие этапа не должно замедлиться.
12. Выгрузка в разделе «Статистика» в рамках задачи не дорабатывается.
